# 🚩 STIKERpop — Захват Тараза (GTA-style Sticker Conquest)

Мобильное приложение для реального захвата города с помощью стикеров (стикер-бомбинг / стрит-арт / партизанский маркетинг).
Построено на Leaflet, HTML5 Canvas и Capacitor 6 (Android).

## 🎮 Как это работает
* **Туман войны (Fog of War):** Весь город Тараз изначально скрыт в плотном тумане.
* **Физический радиус:** Каждый наклеенный стикер открывает реальную площадь вокруг себя (по умолчанию честные 120 метров на Земле).
* **Связные коридоры (GTA 5 Style):** Близко наклеенные стикеры объединяются в единые непрерывные открытые зоны влияния без швов и артефактов.
* **Районы Тараза:** 23 микрорайона и массива города с честным подсчётом процента контроля и прогресс-барами.
* **Тактические пины:** 3D-флажки с отображением состояния стикера (🔥 Свежий, 👌 Цел, 🩹 Облезает, 💀 Сорван).

## 🛠 Технологический стек
* **Frontend:** Vanilla JS, HTML5 Canvas 2D (аппаратное ускорение через composite operations), CSS Glassmorphism
* **Картография:** Leaflet + тёмная подложка ArcGIS World Dark Gray Base
* **Мобильная платформа:** Capacitor 6 + Android SDK
* **Геолокация:** `@capacitor/geolocation` + HTML5 Geolocation API

## 🚀 Запуск и сборка

### Установка зависимостей
```bash
npm install
```

### Синхронизация с Android
```bash
npx cap sync android
```

### Сборка APK
```bash
cd android
./gradlew assembleDebug
```
Готовый файл APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
