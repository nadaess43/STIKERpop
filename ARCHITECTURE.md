## 1. Что это вообще

Личная карта захвата города стикерами. Без сервера, без фото (чтобы не палиться), без других людей.

Ядро:
- нажал одну кнопку `НАКЛЕИЛ ЗДЕСЬ` когда физически наклеил → точка сохранилась с GPS;
- карта закрашивает кварталы вокруг точек → видно свою территорию в м²/км²;
- цвет тухнет со временем → мотивирует идти проверять и обновлять;
- районы считаются сами → видно % захвата по зонам;
- напоминалка если давно не клеил.

Принципы:
1. Метка за 3 секунды одной рукой.
2. Все офлайн, все только в телефоне (`localStorage`).
3. Никаких API-ключей. Все тайлы и геокодер бесплатные.
4. Честная геометрия в метрах, а не тупое округление градусов.

## 2. Стек технологий

- **UI:** один файл `www/index.html` — HTML + CSS + JS (ES-модуль). Без React/Vue чтобы собирать за минуты и не тянуть 100МБ.
- **Карта:** Leaflet 1.9.4 с CDN (`unpkg`). Работает внутри WebView.
- **Обертка в APK:** Capacitor 6 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `@capacitor/geolocation`).
  - `www/` копируется в `android/app/src/main/assets/public` и открывается как нативное приложение.
  - GPS берется через `navigator.geolocation` в WebView (системный диалог разрешений) + плагин `@capacitor/geolocation` прописан чтобы в манифест подтянулись права.
- **Сборка:** Gradle 8.2.1 + Android SDK (build-tools 34.0.0/36.0.0, platforms android-34/android-37.0) + Java 17 Temurin.
- **Хранение:** `localStorage` ключи `stikerpop.v2` (активный), `stikerpop.v1` (миграция).

Почему так:
- Flutter нет на машине, ставить долго. Node 24 + Java 17 + SDK уже есть.
- Capacitor позволяет писать карту один раз на JS и сразу паковать в APK без Android Studio.

## 4. Модель данных

`localStorage['stikerpop.v2']` = JSON:

```json
{
  "points": [
    {
      "id": "m123abc",
      "lat": 55.75221,
      "lng": 37.61563,
      "createdAt": 1728768000000,
      "checkedAt": 1728768000000,
      "cond": "ok",
      "district": "центр",
      "note": "череп красный, столб у остановки",
      "autoDist": "Тверской"
    }
  ],
  "remDays": 7,
  "defDist": "",
  "cellSize": 150,
  "radius": 30,
  "showCells": true,
  "showRadius": true,
  "seen": true,
  "filter": "all"
}
```

Поля точки:
- `lat/lng` — округлены до 6 знаков (~10см, хватает).
- `createdAt` — когда наклеил. Не меняется.
- `checkedAt` — когда последний раз подтвердил что живо. Меняется кнопкой «Был тут».
- `cond` — `fire` (свежак), `ok` (норм), `peel` (облезает), `gone` (сорван).
- `district` — ручной район. `autoDist` — авто от Nominatim. Итоговый район = `district || autoDist || 'без района'`.
- Фото НЕТ специально.

Настройки:
- `cellSize` — 75/150/250м. Размер квартала.
- `radius` — 10..200м. Радиус влияния круга.
- `remDays` — через сколько дней орать «давно не клеил».
- `showCells/showRadius` — видимость слоев.

Миграция v1→v2: если `stikerpop.v2` пуст, читаем `stikerpop.v1`, забираем `points/remDays/defDist`.

## 5. Честная геометрия: почему не `round(lat*1000)`

Старая тупая версия делала `Math.round(lat*1000)`. Это градусы, а градус долготы в Москве короче градуса широты. Клетки получались прямоугольниками разного размера.

Новая версия — Web Mercator (EPSG:3857), метры:

```
R = 20037508.34
mx = lng * R / 180
my = ln(tan(pi/4 + lat_rad/2)) / pi * R
lat_rad = lat * pi / 180
```

Обратно:

```
lng = mx / R * 180
lat = (2*atan(exp(my/R*pi)) - pi/2) * 180/pi
```

Клетка:

```
cx = floor(mx / cellSize)
cy = floor(my / cellSize)
key = cx + ':' + cy
```

Границы клетки для отрисовки `L.rectangle`:

```
mx0=cx*size, mx1=(cx+1)*size, my0=cy*size, my1=(cy+1)*size
[[myLat(my0), mxLng(mx0)], [myLat(my1), mxLng(mx1)]]
```

Площадь территории:

```
area_m2 = uniqCells.size * cellSize^2
формат: <1000 → "850 м²", <1e6 → "12 500 м²", иначе "1.25 км²"
```

Пример: cellSize=150м, занято 80 клеток → 80*22500=1 800 000 м² = 1.80 км².

Радиус влияния — обычный `L.circle([lat,lng], {radius: S.radius})`. Leaflet сам считает метры. Это не площадь захвата, а визуал «насколько стикер светит».

Слои:
- `cellsLayer` — прямоугольники-кварталы, цвет по самой свежей точке внутри.
- `radLayer` — круги радиуса.
- `pinsLayer` — сами точки `L.circleMarker`.

## 6. Свежесть и цвета

`age = floor((now - checkedAt) / 86400000)` — полных дней.

| Условие | Цвет | Смысл |
|---|---|---|
| cond=gone | #555 серо-черный, маленькая | сорван, не считается в территорию |
| cond=peel | #ff8a3d оранжевый | облезает, пора проверить |
| age<=7 или fire | #22ff88 зеленый | свежак |
| 8..30 | #ffe14d желтый | норм |
| 31..90 | #ff8a3d оранжевый | стареет |
| >90 | #9a9a9a серый | старый |

Квартал красится по `min(age)` точек внутри. Сорванные точки в площадь не идут вообще.

Кнопка «Был тут — обновить свежесть» ставит `checkedAt=now`. Если было `gone` → становится `ok` (переклеил).

## 7. Районы автоматом (без ключа)

При создании точки вызывается:

```
GET https://nominatim.openstreetmap.org/reverse?lat=..&lon=..&format=json&zoom=14&accept-language=ru
```

Без ключа, лимит ~1 req/sec — для соло хватает. Таймаут 6 сек, при офлайне просто пусто.

Берем первое непустое:
`suburb || neighbourhood || residential || city_district || quarter || town || village || city || county`

Сохраняем в `autoDist`. Если юзер вписал ручной `district` — он главнее.

Статистика по районам:
```
group = district || autoDist || 'без района'
count, pct = count/total*100
бар шириной count/maxCount
```

По месяцам: группировка `YYYY-MM` по `createdAt`, последние 12, высота столбика пропорциональна.

## 8. Экраны и UX-потоки

### 8.1 Главный экран
- Вверху пилюли: точек / живых / территория / кварталов / последняя.
- Под ними фильтры-чипы: Все, Свежие (<=30д), Требуют проверки (>30 или peel), Сорванные, кнопка Список.
- Внизу: ряд мини-кнопок (где я / тык по карте / стата / настройки) + большая `НАКЛЕИЛ ЗДЕСЬ`.
- Центр при пусто: подсказка «Жми зеленую».
- Онбординг при первом запуске (seen=false): 3 пункта + «Погнали».

Потоки:
1. Наклеил → `НАКЛЕИЛ ЗДЕСЬ` → ловля GPS (кнопка `ЛОВЛЮ GPS…`, дизейбл) → `map.setView(...,16)` → `addPoint` → вибрация 30мс → сразу открывается карточка точки → авто-район дотягивается фоном.
   - GPS fail → тост + авто-включение «тык по карте».
2. Без GPS: включаешь «тык: ВКЛ» → тап по карте = точка. Долгое нажатие (contextmenu) = точка всегда, даже без режима.
3. Тап по точке → карточка: координаты, даты, возраст, авто-адрес, 4 кнопки состояния, район, заметка, «Обновить», «Сохранить», «Удалить».

### 8.2 Стата (`statSheet`)
- Территория + бар (ширина = min(100, cells/2) — чисто визуал роста, не % города, т.к. границ города у нас нет).
- Всего/живых/кварталов/радиус/последняя/не клеил.
- По районам с барами и %.
- По месяцам столбики.
- Легенда цветов.
- Экспорт/Импорт/Стереть.

### 8.3 Список (`listSheet`)
- Поиск по `note+district+autoDist`.
- Сортировка по `createdAt` desc, лимит 300.
- Строка: цвет-точка, название (note или район), подстрока (район · дата · возраст), кнопка → перелет `setView(...,17)` + открыть карточку.

### 8.4 Настройки (`setSheet`)
- cellSize select, radius number, remDays number, defDist, чекбоксы слоев.
- Сохранить → `save()+render()+toast`.

Тосты: черный пил `#toast` на 2.2 сек вместо `alert` везде кроме опасных удалений (там `confirm`).

## 10. Карта: почему Esri, а не Carto

Было: `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`
Стало на телефоне писать прямо на тайлах `api key required` — Carto закрыл бесплатный доступ без ключа.

Заменили на безключевые:
- Тёмная по умолчанию: `https://server.arcgisonline.com/ArcGIS/rest/services/Canvas/World_Dark_Gray_Base/MapServer/tile/{z}/{y}/{x}` (© Esri © OSM)
- Светлая запасная: `https://tile.openstreetmap.org/{z}/{x}/{y}.png` (© OSM)
- Переключатель `L.control.layers` справа вверху.

Нужен интернет для первой загрузки тайлов. Сами точки работают офлайн.

Leaflet CSS/JS грузятся с `unpkg` — тоже нужен инет при старте. Если хочешь полный офлайн — надо завендорить leaflet в `www/` (следующий шаг).

## 11. Android: права и сборка

`AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```

Без этих двух GEO-строк кнопка GPS молча не работает на Android 12+.

`capacitor.config.json`:
```json
{"appId":"com.swiftsoft.stikerpop","appName":"STIKERpop","webDir":"www"}
```

Сборка (PowerShell, из корня проекта):
```powershell
npm install
npx cap sync android
$env:ANDROID_HOME="C:\Users\kk951\AppData\Local\Android\Sdk"
./android/gradlew -p android assembleDebug --no-daemon -x lint
Copy-Item android\app\build\outputs\apk\debug\app-debug.apk -Destination "STIKERpop-v1.apk" -Force
```

Грабли:
1. Путь проекта содержит кириллицу `експеременты с вайбкодингом` → Gradle ругается `Your project path contains non-ASCII characters`. Лечится строкой в `android/gradle.properties`: `android.overridePathCheck=true`. Идеально — переехать в `E:\STIKERpop`.
2. `local.properties` должен содержать `sdk.dir=C:\Users\kk951\AppData\Local\Android\Sdk`.
3. Java 17 обязательна (Temurin 17.0.20 стоит). Java 8/21 ломают Capacitor 6.
4. Первый билд ~1.5-2 мин, следующие ~20-25 сек (кэш).

Установка: скинуть `STIKERpop-v1.apk` на телефон → разрешить «неизвестные источники» → дать геолокацию «при использовании».

## 13. Ограничения сейчас и куда расти

- Нет % города от реальной границы — нет офлайн-границ OSM. Бар сейчас относительный. Чтобы было «Ленинский закрашен на 7.3%» — надо скачать GeoJSON районов и считать пересечение клеток с полигоном (turf.js). Реально, но +2-3 часа.
- Нет пушей, нет виджета. Добавляется плагином `@capacitor/local-notifications`.
- Leaflet с CDN — при плохом инете белый экран. Вендорить: `npm i leaflet`, скопировать css/js в `www/`.
- Нет кластеризации — при 2000 точек будет тормозить. Лечится `leaflet.markercluster` или отрисовкой только viewport.
- Нет фото — так задумано.
- Нет туман войны маской — можно добавить 4-й слой: круги 200м светлым, остальное затемнение. Красиво, но жрет батарею при рендере.

Приоритет если дальше пилить: 1) GeoJSON районов для честных %, 2) вендор leaflet офлайн, 3) виджет «территория + давно не клеил».

## 14. Где что править (шпаргалка)

- Цвета свежести → функция `color(p)` в `www/index.html`.
- Пороги 7/30/90 → там же + легенда в `statSheet`.
- Размер квартала по умолчанию → `S.cellSize`, select `#cellSize`.
